Developer notes: Website HMI Badko Kalsel ini dikembangkan sebagai situs organisasi modern berbasis HTML, CSS, dan JavaScript dengan Tailwind CSS untuk tampilan responsif, tema gelap/terang, navigasi interaktif, dukungan bilingual sederhana, serta fitur utama seperti halaman publik, dashboard admin, manajemen konten, dan akses pengguna; ini masih merupakan pre-alpha build yang belum sepenuhnya stabil dan tidak luput dari bug, sehingga perlu pengujian, perbaikan, dan pengembangan lebih lanjut sebelum digunakan secara penuh.
